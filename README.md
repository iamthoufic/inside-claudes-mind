# Inside Claude's Mind

An original song, **"Weighing Every Word"**, sung by a pure-code formant synthesizer while an animated ASCII head shows a playful picture of what's going on inside a language model as it sings.

- One self-contained `index.html`: Web Audio API + plain JavaScript
- No samples, no text-to-speech, no libraries, no external assets
- The voice is a sawtooth "glottis" shaped by three moving formant filters; consonants are shaped noise bursts
- The band (pads, bass, plucks, drums) and the reverb are synthesized too

Open `index.html` in a browser and click or press **Space** to start. **R** restarts.
